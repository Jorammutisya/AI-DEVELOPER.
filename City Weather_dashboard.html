About This Dashboard

This dashboard retrieves live weather data for a city and displays its current conditions, upcoming forecast and country details.

Weather information is provided by OpenWeatherMap. Country details are loaded from a public country dataset.

Internet access is required to retrieve the latest information.

Weather data by OpenWeatherMap · Country data by public countries dataset
