## City Weather Dashboard.

Displays current weather, a 3-day forecast, and country information for any city using the OpenWeatherMap API and a public country dataset.

## Setup

1. Clone the repo.
2. Open `weather_dashboard.html` in your browser.
3. Get a free API key at [openweathermap.org](https://openweathermap.org/).
4. Enter your API key and city name in the dashboard.

## Usage

Open ` City Weather_dashboard.html`, enter a city (e.g., Mombasa), enter your API key, and click **Get Weather**.
